DUDGEON WOW — CLIENT SETUP

Realm:
  Dudgeon Wrath

Client:
  World of Warcraft: Wrath of the Lich King 3.3.5a
  Build 12340

Realm host:
  wowclient.dudgeon.io

REALMLIST SETUP

1. Close World of Warcraft.

2. Find your 3.3.5a client directory.

3. Open:
     Data\enUS\realmlist.wtf

   Depending on the client locale, the locale folder may be named differently.

4. Replace the contents with:

     set realmlist wowclient.dudgeon.io

5. Save the file.

6. Launch the game using Wow.exe.

For current server status and updated setup information:
  https://wow.dudgeon.io/
